Evidence over folklore.

Benchmark the real machine, preserve the starting state, and keep a change only when the measurements support it.

01 / NETWORK

Tail-latency diagnostics

Measures idle and loaded P95 latency, packet loss, jitter, gateway behavior, and NIC counters.

02 / GRAPHICS

Repeatable A/B benchmarks

Uses multi-run PresentMon captures and noise-aware comparisons instead of trusting one lucky run.

03 / SYSTEM

Explicit Windows controls

Registry, services, power, NVIDIA, AppX, and adapter changes remain visible and independently selectable.

04 / APPS

Reviewed app installation

Install or update Chromium, Discord, Steam, Epic Games Launcher, and Logitech Onboard Memory Manager through exact WinGet package IDs.

Built to back out.

The hardened build improves recovery and supply-chain safeguards wherever elevated code or adapter state is involved.

Recovery

Backups before mutation

Registry, service, power, and NIC state are captured before relevant changes. Interrupted network tuning now triggers an emergency rollback to the original adapter snapshot.

Integrity

Verified managed tools

Downloads require HTTPS plus a publisher digest or trusted signature. Tool directories are replaced atomically, restoring the previous installation if deployment fails.
