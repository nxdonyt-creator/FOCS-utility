READ-ONLY CHECKS ON THE ACTUAL PC
- All six custom AC power settings were readable and supported. The existing
  power plan remained active; no plan was created, activated or deleted.
- The installed NVIDIA API found Fortnite and Rainbow Six Siege game profiles
  and read the four selected settings. No driver value was changed.
- Present device enumeration resolved Razer Viper V2 Pro, Apex Pro TKL 2023,
  LIGHTSPEED Receiver and a separately identified Logitech virtual interface.
  Inventory reflects devices connected at the moment of inspection.
- Existing Fortnite graphics keys were inspected without writing the config.
- Native read-only previews were restricted to the non-primary monitor.
  Performance profile cards and the 103-control page were visually inspected.
  The final rebuilt dashboard showed live peripheral identity (including the
  LIGHTSPEED receiver while it supplied input), updated device-group counts,
  live hardware data, the purple interface and no saved mutations.
- The UI helper refused later clicks with "user input was detected in this
  window" while the user worked. Further interactive navigation was stopped;
  a complete final-build click-through of every page/modal was not performed.
  Preview mode blocks settings, reset and restore-point commands and elevation.
  Owned read-only preview processes were stopped after verification.

NOT LIVE-TESTED DURING THIS STUDY SESSION
Applying/resetting actual Windows, NVIDIA, boot, power, game or network settings;
restore-point creation; app installs/removals; encryption/decryption; reconnects;
restarts; optional-feature servicing; firmware; stress/thermal load; anti-cheat
compatibility; and game FPS, frame consistency or click-to-photon improvement.
The user authorized isolated tests and read-only checks only.

Unsupported settings and policies may behave differently across Windows,
driver, browser and game versions. A registry readback does not prove a policy
is honored. The custom power/NVIDIA/graphics profiles need controlled in-game
comparisons; there is no claim of a universal best profile.

Prior UI checks (3.1) covered selection reviews/cancellation, debloat inventory,
app installer inventory/review, DNS/network states and system-control states.
These observations are historical and are not presented as new 3.2 live tests.
